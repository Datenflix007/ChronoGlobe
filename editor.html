Zum Globus

Mach den Globus besser.

Fehler korrigieren, ein Gebiet neu zeichnen oder eine ganz neue Ebene anlegen – von Pyramiden bis zu Klöstern. Jeder Vorschlag braucht Belege und wird vom Projektteam geprüft, bevor er erscheint.

Dein Entwurf bleibt nur in diesem Browser. Es wird nichts hochgeladen, bis du selbst auf GitHub einreichst.
